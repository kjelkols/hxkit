## Navigering

- **Hovedprosjekt**: Se [README.md](../README.md) i rot-mappen
- **Eksempler**: Se `examples/` mappen for praktiske kodeeksempler
- **API-dokumentasjon**: Genereres automatisk fra docstrings
- **Testing**: Se `tests/` mappen og `tests/README.md`

## Bidrag til dokumentasjon

Når du legger til ny dokumentasjon:
1. Legg filer i riktig kategori (bruker/teknisk/utvikler)
2. Oppdater denne oversiktsfilen
3. Sørg for at lenker fungerer
4. Bruk konsistent Markdown-formatering
